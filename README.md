# 🧹 Disk Sanitiser

A Python-based **Disk Sanitiser** tool designed to securely clean unwanted files and free up disk space through automated file scanning and deletion. The project helps users identify unnecessary files and manage storage efficiently.

## 📌 Project Overview

The Disk Sanitiser is an automation-based Python project that scans selected directories or drives, identifies files based on defined conditions, and removes unwanted files.

It can be useful for:

* 🗑️ Removing unnecessary files
* 💾 Freeing up disk space
* 🔍 Scanning files and directories
* ⚙️ Automating disk-cleaning tasks
* 📊 Monitoring storage usage
* 📝 Generating cleaning/log information

## ✨ Features

* Scan files and folders automatically
* Identify unnecessary or unwanted files
* Calculate file sizes and storage usage
* Delete selected files safely
* Count files present in a directory
* Automate the sanitisation process
* Display useful cleaning information
* Simple and easy-to-use Python implementation

## 🔐 Safety

Before deleting files, make sure the selected directory does not contain important personal, system, or application files.

For testing, it is recommended to use a **sample/test directory** first rather than an important system directory.
